# 도전하는 구름

## 주요 변경 사항

- 도전과제가 생겼어요. 입력, 함께하기, 발견, 숨겨진 것까지 네 묶음에 스물네 개가 있고, 설정의 도전과제 탭에서 볼 수 있어요. 기록은 이 컴퓨터에만 남고, 끄거나 지울 수도 있어요.
- 작은 창으로 구름을 다른 일 옆에 띄워 둘 수 있어요. 늘 위에 떠서 누가 소리를 내는지와 음소거만 보여 줘요.
- 소리 탭에서 고른 단축키(Ctrl+Alt+M, Ctrl+Shift+M, Pause)로 어느 프로그램에서든 음소거해요.
- 대화가 편해졌어요. 내 별명이 나오면 눈에 띄고 알려 주고, 자리를 비운 사이 온 메시지는 "여기부터 새 메시지" 아래에 모여요. 위아래 화살표로 보냈던 메시지를 다시 불러오고, 남은 글자 수도 보여 드려요.
- 구름에 날씨가 생겼어요. 다들 바쁘게 입력할수록 흐려지고, 비가 오고, 폭풍이 쳐요. 홈에는 계절마다 눈, 꽃잎, 낙엽이 내려요. 외관 탭의 "계절과 날씨 효과"로 둘 다 끌 수 있어요.
- 트레이 메뉴에서 음소거, 나가기, 옵션을 바로 할 수 있어요.
- 키보드만으로도 쓸 수 있어요. Tab과 Shift+Tab으로 컨트롤 사이를 옮겨 다니고, Enter와 Space로 눌러요. 화살표와 Page Up/Down, Home, End로 슬라이더, 목록, 탭, 이모지를 고르고, Ctrl+Tab으로 설정 탭을 바꿔요.
- 대화 메시지, 변경 내역, 저장소 키의 지문, 질문 문구를 선택하고 복사할 수 있어요. 글자 위에서 오른쪽 클릭, 메뉴 키, Shift+F10으로 메뉴를 열어요.
- 곳곳에 작은 비밀이 숨어 있어요.
- 실행 파일이 2.2 MB에서 1.5 MB로 가벼워졌어요.
