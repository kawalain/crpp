# 손에 익는 구름

## 주요 변경 사항

- 키보드만으로도 쓸 수 있어요. Tab과 Shift+Tab으로 컨트롤 사이를 옮겨 다니고, Enter와 Space로 눌러요. 화살표와 Page Up/Down, Home, End로 슬라이더, 목록, 탭, 이모지를 고르고, Ctrl+Tab으로 설정 탭을 바꿔요. 지금 어디에 있는지는 스킨마다 그 시절의 모습으로 보여 드려요.
- 대화 메시지, 변경 내역, 저장소 키의 지문, 질문 문구를 선택하고 복사할 수 있어요. 입력 칸에서는 두 번 클릭하면 단어를, 세 번 클릭하면 문단을 선택하고, Ctrl과 함께 단어 단위로 움직이고 지워요.
- 글자 위에서 오른쪽 클릭, 메뉴 키, Shift+F10으로 메뉴를 열어요. 잘라내기, 복사, 붙여넣기, 삭제, 모두 선택이 있고, 대화 속 링크에서는 주소 복사가 먼저 나와요.
- 대화 속 링크가 자기 색으로 보여요.
- 레트로 스킨에서 Alt나 F10을 누르면 메뉴 막대로 들어가고, 메뉴 글자에 밑줄이 생겨요.
- 실행 파일이 2.2 MB에서 1.5 MB로 가벼워졌어요.
