# 갈아입는 구름

## 주요 변경 사항

- 구름에 더해 옛 데스크톱을 닮은 레트로 스킨이 생겼어요. 외관 탭에서 테마와 다크 모드(끔, 켬, 시스템 따르기)를 함께 골라요.
- 스킨과 소리는 필요한 것만 받아요. 처음엔 기본 스킨만 받고, 나머지는 고를 때 받아요. 다른 저장소를 주소로 추가해 그곳의 스킨과 소리 팩도 쓸 수 있어요.
- 영어를 지원하고, 한국어 문구도 더 부드럽게 다듬었어요.
- 소리 설정에 "울림"이 생겼어요. 끔, 사무실, 넓은 공간 중에서 고를 수 있어요.
- 다른 창 뒤에 있을 때 그래픽 메모리를 비워요.
- 버튼은 손을 뗄 때 눌리고, 한국어로 입력할 때 선택한 글자가 제대로 바뀌어요.
