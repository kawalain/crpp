# 든든한 구름

## 주요 변경 사항

- 서버를 고를 수 있어요. 첫 로그인 화면의 "서버 바꾸기"나 시스템 탭의 고급 항목에 주소를 넣으면, 그 서버가 대답하는지 확인하고, 내 입력과 대화, 계정이 그 서버로 간다는 것을 한 번 더 여쭌 뒤에 바꿔요. 서버마다 계정을 따로 기억해서, 돌아가면 그 계정이 그대로 있어요.
- 앱이 갑자기 꺼지면 다음에 켤 때 알려 드려요. "올리기"를 누르면 보고서를 채운 GitHub 이슈 페이지가 열리고, 내용을 보신 뒤 직접 올리시면 돼요. 앱이 스스로 보내는 것은 없고, 보고서에는 입력, 채팅, 이름, 주소가 들어 있지 않아요.
- GitHub 이슈에서 크래시, 버그, 제안을 받아요. 보안 문제는 공개 이슈 대신 비공개로 알려 주세요.
- 더 튼튼해졌어요. 목록의 범위를 벗어난 접근과 엉뚱한 곳으로 가는 호출을 막아요.
- 내려받은 파일은 내용마다 한 벌만 보관해요. 여러 스킨과 저장소가 같은 파일을 써도 한 번만 받고, 더 쓰지 않는 파일은 치워요.
- 공식 파일은 이제 GitHub에서만 받아요.
- 저장소 주소를 누르면 그 저장소의 페이지가 열려요.
