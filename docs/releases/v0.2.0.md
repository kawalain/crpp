# 갈아입는 구름

## 주요 변경 사항

- 이제 모습을 고를 수 있어요. 구름에 더해 1990년대와 2000년대 초 데스크톱을 닮은 레트로 스킨이 생겼어요. 고전, 루나 블루, 루나 홈스테드, 루나 메탈릭 테마가 있고, 모두 다크 모드를 지원해요.
- 외관 탭에서 테마와 다크 모드(끔, 켬, 시스템 설정 따르기)를 한 번에 골라요. 아직 받지 않은 테마는 고르는 순간 받아요.
- 스킨과 소리는 필요한 것만 받아요. 처음 실행할 때는 기본 스킨만 받고, 다른 것은 고를 때 받아요. 업데이트는 앱 뒤에서 조용히 받아 두었다가 다음 실행부터 써요.
- 다른 저장소를 주소로 추가해서 그곳의 스킨과 소리 팩을 쓸 수 있어요. 추가하기 전에 서명 키의 지문을 보여 주고, 키가 바뀌면 알려 드려요.
- 영어를 지원해요. 처음에는 운영체제 언어를 따르고, 외관 탭에서 바꿀 수 있어요. 한국어 문구도 더 부드럽게 다듬었어요.
- 소리 설정에 "울림"이 생겼어요. 끔, 사무실(기본), 넓은 공간 중에서 고르고, 가상 서라운드와 따로 켜고 끌 수 있어요. 처음 들어온 사람들은 서로 멀리 떨어져 앉아요.
- 다른 창 뒤에 있을 때 그래픽 메모리를 비워요. 비우기까지 기다리는 시간은 시스템 탭의 고급 설정에서 고를 수 있어요.
- 버튼은 이제 손을 뗄 때 눌려요. 누른 채로 벗어나면 취소돼요.
- 한국어를 입력할 때 선택한 글자가 새 글자로 바뀌지 않던 문제를 고쳤고, 입력란에서 끌어서 선택할 수 있어요.
